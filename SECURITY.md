# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please **do not** open a public issue.

Instead, please report security issues by creating a private advisory via GitHub's [Security Advisories](https://github.com/magnusp/logback-single-writer-jdbc-appender/security/advisories) feature or by contacting the maintainer directly.

We take all security reports seriously and will acknowledge receipt within 48 hours.
